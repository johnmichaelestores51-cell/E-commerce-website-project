# ShopEase

ShopEase is an e-commerce demo built with React and Vite.

## Run the project

Install [Node.js](https://nodejs.org/) first. Then, from the repository folder, open a terminal and run:

```powershell
cd shopease
npm install
npm run dev
```

Open the local URL printed in the terminal (usually `http://localhost:5173`) to view the app. Keep the terminal running while you use the site; press `Ctrl+C` to stop the development server.

If your terminal is already in the `shopease` folder, skip `cd shopease` and run the other two commands.

## Production build

```powershell
cd shopease
npm install
npm run build
```

The production files are generated in `shopease/dist`.
